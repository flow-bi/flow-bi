# DESIGN.md

## 1. 문서 목적과 범위

- 목적: 프런트엔드의 공통 UI·UX·반응형·접근성 기준을 정의한다.
- 범위: 화면의 시각적·상호작용 규칙과 공통 패턴만 다룬다.

기능별 요구사항, 업무 규칙, 인수 조건은 `docs/product-specs/`의 승인된 Product Spec을 우선한다. 구조, 상태 관리, API 계층의 세부 규칙은 FRONTEND.md를 따른다.

## 2. 공통 원칙

- 사용자가 현재 위치와 다음 행동을 빠르게 이해할 수 있어야 한다.
- 중요한 상태와 오류는 색상만으로 전달하지 않는다.
- 파괴적 행동은 시각적으로 구분하고 확인 절차를 제공한다.
- PC와 모바일에서 핵심 흐름을 사용할 수 있어야 한다.
- 자동 생성된 내용과 실제 시스템 데이터 또는 실행 결과를 구분한다.

## 3. 시각 시스템

- Tailwind 설정에서는 역할 기반 토큰을 사용한다: background, surface, primary, secondary, text-primary, text-secondary, text-disabled, border, success, warning, danger, info, focus-ring.
- 컴포넌트에서 임의의 Hex 값을 반복하지 않는다.
- 테마 변경은 색상 토큰만 교체하고 컴포넌트 의미는 유지한다.
- 초기 테마 후보는 다음과 같다.

### Sky Theme

- 기본 배경 후보: `#EDF1F6`
- 흰색 Surface와 하늘색 계열 강조색 조합

### Purple Theme

- 대표 강조색 후보: `#5541A4`
- 흰색 Surface와 연보라 계열 보조색 조합

색상 후보는 디자인 토큰 확정 전 참고값이다. 배경과 글자, 버튼과 상태 색상은 접근 가능한 명암 대비를 검증한 후 확정한다.

## 4. 레이아웃과 컴포넌트

- 화면은 제목, 주요 행동, 보조 필터, 본문 순서로 정보 위계를 구성한다.
- 작은 화면에서는 한 번에 하나의 주요 작업을 우선하고 보조 패널은 Overlay 또는 전체 화면으로 전환한다.
- 버튼은 Primary, Secondary, Tertiary, Danger의 의미를 구분한다.
- 아이콘만 사용하는 버튼에는 접근 가능한 이름을 제공한다.
- 폼은 Label, 입력, 도움말, 오류 메시지를 연결한다.
- 비활성화와 읽기 전용 상태를 구분한다.
- 모달과 사이드 패널은 제목, 닫기 수단, 포커스 이동을 명확히 제공한다.
- 모달을 닫으면 이전 포커스로 복귀하고, 저장되지 않은 입력이 있으면 닫기 전에 확인한다.
- 상태 표시는 텍스트, 아이콘, 색상을 함께 사용한다.

## 5. 상태와 상호작용

- 초기 로딩, 빈 상태, 오류, 권한 거부, 인증 만료를 명시적으로 표현한다.
- 빈 상태는 오류처럼 보이지 않도록 가능한 다음 행동을 안내한다.
- 오류는 발생 위치 근처에 표시하고 가능하면 재시도 수단을 제공한다.
- 제출 중 중복 요청을 막고, 저장·수정 작업은 완료 확정 후에 성공 상태로 전환한다.

## 6. 접근성 및 콘텐츠

- 모든 기능은 키보드로 접근 가능해야 한다.
- 포커스 표시를 제거하지 않고, 모달과 패널의 포커스를 관리한다.
- 시맨틱 Landmark, Heading, Label, 오류 연결을 유지한다.
- 색상만으로 상태를 전달하지 않는다.
- 복잡한 시각 정보에는 목록이나 텍스트 기반 대체 접근 경로를 제공한다.
- 버튼 문구는 결과가 드러나는 동사로 작성하고, 내부 용어는 사용자 메시지에 그대로 노출하지 않는다.
- 날짜·시간과 상태 표현은 화면 간 일관되게 유지하고, 오류 메시지는 원인과 사용자가 취할 행동을 설명한다.

## 7. 검증 체크리스트

- 데스크톱과 모바일에서 핵심 흐름이 가능한가
- 로딩, 빈 상태, 오류, 권한 상태가 있는가
- 키보드만으로 조작 가능한가
- 포커스가 올바르게 이동하고 원래 위치로 복귀하는가
- 위험한 행동에 확인 절차가 있는가
- 색상 없이도 상태를 이해할 수 있는가
- 변경 불가 필드와 상태가 명확한가

## 8. 미결정 사항

- 확정 디자인 토큰과 전체 색상 팔레트
- Typography와 아이콘 세트
- 정확한 반응형 Breakpoint
