# 작업 계획: calendar-07

## 1. 기본 정보

### 사용자 요청

- 일정 수정 중 모달 바깥을 클릭했을 때 표시되는 `수정 내용을 버릴까요?` 확인 모달의 레이아웃을 수정한다.
- `계속 수정`, `수정 취소하고 닫기` 버튼이 모달 카드 밖으로 벗어나지 않고 카드 내부 footer에 표시되도록 한다.

### 작업 목적

수정 폐기 확인 모달의 잘못된 중앙 배치 제약을 바로잡아 제목, 닫기 버튼과 두 업무 액션이 모달 배경 및 경계 안에 안정적으로 포함되게 한다. 기존 수정 상태 보존·폐기 동작과 접근성 계약은 유지하고, 실제 요소 경계를 검증하는 회귀 테스트로 같은 문제의 재발을 막는다.

### 작업 유형

- bugfix
- test

### 관련 설계 문서

- Product Spec: `docs/product-specs/calendar.md`
- Design Doc: `frontend/DESIGN.md`
- Architecture: `frontend/FRONTEND.md`
- 선행 작업: `docs/plans/complete/calendar-06.md`
- 기타 참고 문서: `CONVENTIONS.md`

### 확인된 원인

- 수정 폐기 확인 모달 카드에 `fixed inset-1/2`가 적용되어 상·하·좌·우 위치가 모두 50%로 지정된다.
- 상·하 제약이 동시에 적용되면서 카드의 계산 높이와 배경 경계가 내용 높이를 정상적으로 감싸지 못해 footer 버튼이 카드 밖에 있는 것처럼 표시된다.
- 기존 Cypress 검증은 버튼 간 겹침과 문서 전체 가로 overflow만 확인하고, 버튼이 실제 alertdialog 카드 경계 안에 포함되는지는 확인하지 않았다.
