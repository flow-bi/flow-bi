# 작업 계획: meeting-room-03

## 1. 기본 정보

### 사용자 요청

회의실 검색과 예약 패널의 시작·종료 시간을 키보드 입력에서도 10분 단위로 제한한다. 사용자가 소유한 예약에만 일반화된 `예약 수정` 행동을 제공하고, 예약 생성·수정 패널은 바깥 영역 클릭으로도 닫을 수 있게 한다. 회의실의 `예약하기`를 누르면 임의의 기본 시간이 아니라 마지막으로 적용한 검색 필터의 날짜와 시간대로 예약 입력을 시작하도록 개선한다.

### 작업 목적

회의실 검색 조건과 예약 입력의 시간 규칙을 일치시키고, 예약 생성·수정 진입점과 패널 종료 동작을 사용자가 예측할 수 있게 만든다. 기존 소유권 표시인 `canEdit`을 유지해 다른 사용자의 예약에는 수정 행동을 노출하지 않으며, 저장하지 않은 입력 보호와 포커스 복귀를 훼손하지 않는다.

### 작업 유형

- bugfix

- Design Doc: `frontend/DESIGN.md`
- Architecture: `frontend/FRONTEND.md`
- 기타 참고 문서: `AGENTS.md`, `frontend/AGENTS.md`

## 3. 전체 완료 조건

- 모든 Task의 구현 항목이 완료되어야 한다.
- 모든 Task의 검증 항목이 통과해야 한다.
- 검색과 예약 폼의 10분 단위 규칙, 소유 예약 수정, 바깥 클릭 종료, 적용된 검색 시간 초기화가 정상적으로 통합되어야 한다.
- 각 Task의 수정 범위가 해당 Task의 `수정 가능 경로`를 벗어나지 않아야 한다.
- 각 Task의 `수정 금지 경로`에 변경이 없어야 한다.
- 관련 Product Spec 및 Frontend 설계 기준과 실제 구현이 일치해야 한다.
- 전체 Frontend lint, typecheck, unit test, Cypress와 build가 통과해야 한다.
- 전체 `quality_score`가 `90` 이상이어야 한다.

## 4. 전체 실패 조건

- 하나 이상의 필수 Task가 실패함
- 필수 검증 명령이 실패함
- Task별 수정 가능 경로 밖의 변경이 발생함
- Task별 수정 금지 경로에 변경이 발생함
- 관련 Product Spec 또는 Frontend 설계 기준과 충돌함
- 비소유 예약 수정 노출, 잘못된 시간 예약 또는 저장하지 않은 입력 유실 회귀가 발생함
- 남은 문제가 사용자 확인 없이 방치됨
