# 시스템 관리자 Product Spec

## 기능 목적

`SYSTEM_ADMIN`이 인사·역할 관리 권한과 분리된 최소 시스템 운영 기능을 수행하도록 범위와 접근 조건을 정의한다. `ADMIN`은 동일 권한을 명시적으로 보유하므로 같은 기능을 사용할 수 있다.

## 역할 경계

- `SYSTEM_ADMIN`은 `SYSTEM_MONITOR`, `ACCOUNT_STATUS_READ`, `THEME_MANAGE`, `ROOM_RESOURCE_MANAGE`만 가진다.
- `ADMIN`은 위 권한을 포함한 전체 8개 권한을 명시적으로 가진다.
- `SYSTEM_ADMIN`은 직원 정보 변경, 계정 상태 변경, 비밀번호 초기화, 퇴직 처리, 팀 관리, 역할 부여·회수를 수행할 수 없다.
- `SYSTEM_ADMIN`과 `HR_ADMIN`을 함께 가져도 `ROLE_MANAGE`와 `PRIVILEGED_ACCOUNT_MANAGE`가 없으므로 `ADMIN`으로 취급하지 않는다.
- 메뉴 노출과 무관하게 각 API에서 해당 권한을 검사하고 기본 거부한다.

## 기능별 케이스

| 케이스 | 권한 | 허용 데이터와 동작 | 명시적 제한 |
| --- | --- | --- | --- |
| 서비스 상태 조회 | `SYSTEM_MONITOR` | 서비스 구성요소의 가용 상태와 점검용 요약 조회 | 상태 변경, 프로세스 제어 불가 |
| 시스템 로그 조회 | `SYSTEM_MONITOR` | 운영에 필요한 필터링된 시스템 로그 조회 | 비밀번호·세션 ID·토큰·과도한 개인정보 노출 금지 |
| 오류 상태 조회 | `SYSTEM_MONITOR` | 오류 코드, 발생 구간, 처리 상태 등 운영용 정보 조회 | 업무 데이터 임의 열람 불가 |
| 계정 상태 조회 | `ACCOUNT_STATUS_READ` | 사번, `ACTIVE`/`INACTIVE`, `EMPLOYED`/`TERMINATED` | 이름·연락처·이메일·역할 상세 조회 및 모든 변경 불가 |
| 회사 테마 관리 | `THEME_MANAGE` | 승인된 후보 중 대표 테마 조회·변경 | 임의 CSS·스크립트·기능 설정 불가 |
| 회의실 자원 관리 | `ROOM_RESOURCE_MANAGE` | 회의실 사진, 장비 종류, 회의실별 장비 연결 관리 | 예약 소유권 우회나 일반 일정 변경 불가 |

## 보안 및 데이터 계약

- 시스템 로그와 오류 응답은 비밀정보를 마스킹하고 운영에 필요한 최소 정보만 제공한다.
- 계정 상태 조회는 직원 관리 목록을 재사용해 과도한 개인정보를 반환하지 않으며 별도 최소 응답 DTO를 사용한다.
- 테마와 회의실 자원 변경은 일반 상태 변경 이벤트로 감사 가능하게 기록한다. 역할 부여·회수 이력 제외 결정은 이 기록에 영향을 주지 않는다.
- 모든 변경 요청은 CSRF 보호, 입력 검증, 서버 권한 검사를 적용한다.
- `SYSTEM_ADMIN` 역할 변경은 `ADMIN`의 역할 관리 API에서만 이루어지고, 변경 후 대상 사용자의 모든 세션을 무효화한다.

## 제외한 요구사항

- 기능 토글, 임의 전역 설정, 배포·재시작·데이터베이스 직접 조작
- 직원·팀·역할·비밀번호 관리
- 원문 비밀정보, 인증 토큰, 세션 식별자 조회
- 조직별 시스템 관리자와 역할·권한 카탈로그 CRUD
- 역할 부여·회수 이력 조회

새 시스템 운영 기능은 기존 권한에 임의로 포함하지 않고 별도 Product Spec에서 데이터 범위, 변경 영향, 권한 코드를 검토한 뒤 추가한다.

## 인수 조건

- `SYSTEM_ADMIN`은 정의된 네 권한의 기능만 사용할 수 있고 인사·역할 관리 요청은 `403`으로 거부된다.
- `ADMIN`은 같은 시스템 운영 기능을 명시적 권한으로 사용할 수 있다.
- 계정 상태 조회는 사번과 두 상태만 반환한다.
- 로그·오류·변경 응답에 비밀정보 또는 과도한 개인정보가 포함되지 않는다.
- 테마와 회의실 자원 관리의 세부 권한은 관련 Product Spec과 동일하다.

## Scope Decision

- In Scope: 시스템 상태·로그·오류 조회, 최소 계정 상태 조회, 회사 테마, 회의실 사진·장비 관리의 권한 경계.
- Out of Scope: 임의 시스템 설정, 배포 제어, 인사·팀·역할 관리, 구현 API 상세와 UI 상세.
- Moved: 직원·팀·역할 관리는 `admin.md`, 테마 동작은 `global-layout.md`, 회의실 자원 동작은 `meeting-room.md`로 이동한다.

## 관련 Product Spec

- `admin.md`
- `auth.md`
- `global-layout.md`
- `meeting-room.md`

## 미확정 사항

- 없음. 새로운 운영 기능은 별도 Spec에서 확정한다.
